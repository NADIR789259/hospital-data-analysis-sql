# Hospital Data Analysis using SQL

## Project Overview
This project involves analyzing hospital data using SQL to generate actionable insights related to patients, doctors, departments, and medical expenses.  
The project is designed for data analyst portfolio and interview preparation.

## Dataset
Table Name: Hospital

Columns:
- hospital_name
- location
- department
- doctors_count
- patients_count
- admission_date
- discharge_date
- medical_expenses

## Key Analysis Performed
- Calculated total number of patients across hospitals
- Computed average number of doctors per hospital
- Identified top 3 departments with the highest patient count
- Found the hospital with the maximum medical expenses
- Analyzed daily average medical expenses
- Determined the longest hospital stay using date difference
- Calculated total patients treated per city
- Computed average length of stay per department
- Identified the department with the lowest patient count
- Generated monthly medical expenses report

## SQL Concepts Used
- Aggregate Functions (SUM, AVG, MAX)
- GROUP BY and ORDER BY clauses
- Subqueries
- Date arithmetic and date functions
- Data summarization and reporting
